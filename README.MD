# ⏱️ Smart Stopwatch Web Application

A modern and responsive Stopwatch Web Application built using **HTML, CSS, and JavaScript**. The application provides accurate time tracking with Start, Pause, Reset, and Lap functionalities in an elegant and user-friendly interface.

---

## 📌 Features

- ▶️ Start Stopwatch
- ⏸ Pause Stopwatch
- 🔄 Reset Stopwatch
- 🏁 Record Unlimited Lap Times
- ⏱ Millisecond Precision
- 📱 Fully Responsive Design
- 🎨 Modern Glassmorphism UI
- ⚡ Smooth Animations
- 💻 Built with Pure HTML, CSS & JavaScript

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
